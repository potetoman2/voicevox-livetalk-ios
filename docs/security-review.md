# 2.8 セキュリティ確認

2026-10-08。ソース確認・自動テスト・配布物検査の対象を記録。独立した侵入試験、実機の広告通信検査、正式な商用接続の検証は未完了。安全性や審査通過を保証するものではない。

| 確認対象 | 対応 |
|---|---|
| 他のローカルHTMLからネイティブ機能を使える範囲 | index.htmlの正規化したファイルパス、WebView、main frameを限定。URL単体の判定をSwiftで検証 |
| 第三者AI送信の同意 | OAuthだけに任せず、送る内容とOpenAIを明示。未同意の復元・送信・CarPlayを拒否 |
| 端末データの消去 | 全アカウントのKeychain項目を削除。更新中トークンは取消と選択アカウント検証で再保存を防止。遠隔の記録削除とは区別 |
| 合成音声 | 一時WAVを完全ファイル保護し、再生・停止・次回起動で除去。待機の音声は定型のみメモリーに保持 |
| ログと書き出し | 会話・トークン・URLを診断に書かない。時間と定型処理名のみ。設定にトークンを入れない |
| 返答のストリーミング | SSEイベントは結合後256KiB・4096行まで。空のdata行の無制限蓄積と結合時の改行の見落としを修正。部分行も上限、UTF-8・改行形式・境界・次イベントへのリセットを試験 |
| OAuthとAPI | state・nonce・PKCE、IDトークン署名、ループバック127.0.0.1、TLS、トークン更新時の取消判定、リダイレクト拒否を維持 |
| 検索結果 | 未信頼の情報として扱う指示を維持。HTMLを描画しない。リンクはhttp(s)・資格情報なし・明示タップのみ |
| ビルド供給元 | 固定バージョンの公式ライブラリとライセンスを維持。GitHub ActionsをコミットSHAに固定。公開ソースの秘密情報検査をCIへ追加 |
| 購入権利 | StoreKit 2の検証済み・対象アプリ・対象SKU・非消耗型・未失効だけを広告除去に使用。設定のpaidでは解除しない。購入JWS・カードを画面、診断、設定、開発者サーバーへ渡さない |
| 購入の競合 | 操作前にロック、購入前にも権利を再確認。同時の権利確認は全呼び出し元が結果を待つ。復元のApple同期は明示操作だけ |
| キャンセル・返金 | 承認待ちは権利なし。キャンセル・通信失敗でロック解除。返金・取り消しを監視。Apple StoreKit Testingと登録商品での実機Sandboxを区別 |
| 広告の開始条件 | 無料の権利確認・版ごとの明示同意・最新のUMP確認後だけSDK開始。設定画面のみ。通話・読み上げ・CarPlay・購入・背景・モーダルでは表示しない |
| 遅れて届く広告処理 | 中断・削除・撤回の世代番号、購入権利・音声状態を各非同期処理の完了時に確認。復帰しても古い確認画面の選択で同意が復活しない |
| 年齢と広告障害 | 次の要求ごとに年齢設定を反映。失敗時は非表示、明示操作でのみ再試行。広告画面の表示元を終了まで保持し、正しい終了通知で解除 |
| 広告への情報 | 会話・音声・GPTアカウント・トークン・参照URLを広告要求へ付けない。個人向け最適化・同一アプリIDを無効化、IDFA許可を求めない。SDK自身の処理は実通信を確認する |
| 販売用ビルド | 実際の承認・契約・登録・検証が未完了なら停止。評価版の課金・収益広告は無効。本番の商用GPT接続アダプターは未実装 |
| 広告収益の有効化 | 購入の有効化とは分離。`revenue_enabled`状態と実際のAdMob配信準備・発行元・同意・実機検証がそろうまでは、本番IDでもSDKの広告処理を開始しない |

販売前には実端末で、通信中断、アカウント切替、同意の撤回、取消中のトークン更新、長時間会話、端末ロック、リンク、復帰、購入復元を再確認する。外部レビューでKeychain、OAuth、依存ライブラリ、データフローとビルド設定を確認する。侵入試験で未確認の部分を「問題なし」と扱わない。

広告の実通信と統合マニフェストからApp Storeの申告を確定する。`release/store-readiness.json`の商用許可・本番検証フラグは模擬テストだけでは変更しない。情報の範囲は[data-inventory.md](data-inventory.md)、広告の試験は[ad-validation.md](ad-validation.md)を参照。
