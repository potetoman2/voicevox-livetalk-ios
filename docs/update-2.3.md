# LiveTalk 2.3

2.2は利用者から「応答速度よし。検索よし」と報告を受けた。2.3で追加した待機音声・同意・削除の実機検証とは区別する。

調べものを受け付けると、端末内のVOICEVOXで「うん、調べてみるね」と知らせる。通常の即答は待機音声を省き、0.9秒を超えると「ちょっと待ってね」。長い待機では14秒以降に追加案内を一度だけ。第一の返答・終了・割り込み・背景移行・音声中断で止める。GPTへの送信や返答の合成は待機音声の終了を待たない。待機音声を会話の履歴・応答時間の測定に混ぜない。

固定の短い音声をメモリーに先に準備し、待ち時間の追加を抑える。「聞き取った内容」を画面に表示。「声と設定」の会話テンポ欄で待機音声を無効にできる。声の設定・音量を反映し、音量0では再生しない。

OpenAIへの送信の同意・撤回と全接続情報の削除、ネイティブ操作元の限定、一時音声の保護、ビルド依存の固定、販売用ビルドの検査を追加。詳細は[公開準備](commercial-preparation.md)と[セキュリティ確認](security-review.md)。

このIPAは引き続き無料Apple Accountで署名する個人評価版。販売・商用ChatGPT接続・CarPlayの承認は未完了。
