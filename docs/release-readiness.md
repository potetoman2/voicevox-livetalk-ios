## データの扱い（実装確認）
音声合成と対応端末の音声認識は端末内。貼り付けは明示的なボタン操作時のみ。
設定はiOS UserDefaults。合成WAVは一時ファイルで再生後・停止時・起動時に削除。診断ログは固定した出来事のラベルのみ、セッション中のみ。
実験ChatGPT画面はWKWebViewのログイン状態を保存し、質問と返答はOpenAIで処理される。LiveTalkは認証情報を読まない。
通信・認証の仕組みはデータを一切送らない意味ではない。アプリ削除時の保存データ、OpenAI側の履歴、ユーザーが書き出した設定の扱いを公開方針に記載する。
