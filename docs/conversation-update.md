# 2.1 音声会話への更新
2026-10-06。ユーザーから、手動の貼り付け読み上げではなく自然な音声会話と親しみやすい配色への変更を依頼されました。公式ログイン方式への切り替えも明示的に承認されました。

変更：通話をホームの主操作にし、緑を暖かい白・淡いブルー・ピーチへ変更。APIキーを入力せずにChatGPTの利用枠を使うOAuth接続、本人確認、Keychain保存・更新・ログアウト、アカウントとモデル選択、公式Responsesのストリーミング、短文先行合成、無音による発話終了、連続した聞き取り、割り込みを追加しました。

2.0までの20回の修正記録は、その時点の検証として保持しています。今回を20回目の検証に含めたり、過去の実機起動を2.1の実機検証としたりしていません。

Windowsでの会話・UIの自動検証：58項目が合格。実際のブラウザー描画でも320 / 390 / 768幅、文字拡大、ダークモードを確認しました。音声・ログインは模擬です。
MacではOAuth戻り先・SSE・RSA署名、音声ターン、既存入力URL、梱包を検証し、iPhone用の実行ファイルをコンパイルします。実行結果は成果物と同時に別のビルド検証報告へ保存します。

実機で残る確認：iPhoneのブラウザーから127.0.0.1へ戻るOAuthログイン、利用枠の対応、VOICEVOX発声、認識・返答時間、スピーカーの交互会話、イヤホンでの割り込み、長時間使用。
ユーザーの認証情報はこの開発・ビルドへ使用していません。

販売：公式接続の公開ソース・ローカルアプリ向け方式を個人評価で使用。有料アプリへの提供にはOpenAIの申請・条件確認が必要で、今回は販売許諾を取得していません。Appleと音声の販売条件確認も残ります。
