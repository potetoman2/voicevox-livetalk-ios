# LiveTalk 2.4 — 個人向けの公開準備

無料の広告版と、広告除去980円の買い切りを同じアプリで提供する方針です。通常の会話・検索・声設定は同じで、法人プランや月額課金は設けません。サポート：doude424@gmail.com。

StoreKit 2による検証済みの非消耗型購入、復元、更新・返金監視、同時購入防止を実装。Googleの公式広告・同意SDKを固定して組み込み、会話・購入・CarPlay・バックグラウンドで広告を停止します。購入確認と広告の同意が整うまで広告SDKを開始しません。アプリの同意撤回時は広告も停止し、購入権利はAppleに残します。

公開準備版では実課金・収益広告を無効化しています。広告テストは本人が説明を確認して有効にした場合だけです。Apple・AdMobの所有者登録、商用OpenAI許可、本番接続、音声権利の最終確認、決済と広告の実機・通信検証、正式な運営者情報と政策URL、ストア審査が残ります。

Macのビルド環境をXcode 26.3に更新し、提出に必要なXcode/iOS SDK 26以上を検査します。コンパイル、模擬テスト、ソース検査を、実決済の成功や公開承認とは区別して記録します。2.0の20回改善は過去の記録として保持し、今回20回の実機・決済試験を実施したとは表示しません。
