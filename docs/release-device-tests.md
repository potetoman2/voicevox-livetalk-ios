# 販売前の実機検証票

2026-10-07。すべて未実施。模擬テスト、Macでのコンパイル、StoreKit Testingは本票の代わりにならない。承認済みの接続・本番と同じ配布設定・登録商品・テスト端末を用意してから実施する。収益広告を自己クリックしない。

各試験に、端末／OS、アプリbuild、ソースとIPAのSHA256、アカウントの区分（認証情報なし）、手順、実測結果、再現、合否、修正後再試験、確認者・日付を記録する。失敗・未確認をpassにしない。マイク会話・個人情報を証跡へ無断で含めない。

| ID | 操作 | 合格条件 |
|---|---|---|
| A01 | 初回・旧版から更新、AI未同意 | 接続の復元・質問送信が始まらない |
| A02 | 13〜17歳、成人、取消、未確認区分 | 有効な本人申告と保護者同意の区分だけを保存。未成年から成人広告設定へ抜けない |
| A03 | マイク／音声認識拒否、オフライン | 対処がわかる表示。クラッシュ・繰り返し許可要求なし |
| A04 | 日本語音声認識を端末内で使用 | 非対応機種は停止。原音声を外部AI／広告へ送らない |
| A05 | ログイン・取消・期限、別アカウント | 正規戻り先・正しいID署名とアカウントだけを受け入れる |
| A06 | 返答中のロック・背景・着信 | 音声・マイク・要求を停止、勝手に再開しない |
| A07 | 会話終了直後に遅い応答を到着 | 古い返答・音声・マイクが再開しない |
| A08 | イヤホン割込み／抜線、スピーカー | 割込み、音声順序、自己音声誤検出防止が動く。音量が過大にならない |
| A09 | 日付・最新検索・利用枠／検索非対応 | 端末日時、出典、未確認の区別。検索中の受付／待機を短い声で知らせる |
| A10 | 長文・長時間会話、メモリ不足 | 応答停止・チャンク順序・履歴上限。発熱と応答時間も実測 |
| A11 | 同意撤回中のトークン更新・返答 | Keychain再保存、本文表示、音声、広告再開を抑止 |

| A13 | 診断・設定書出し・サポート | トークン／本文／メール／参照URLを混入せず、問い合わせ自動送信なし |
| P01 | 登録商品を初回購入／取消 | 正しいApple価格・SKU。成功検証時だけ広告除去。取消は権利なし |
| P02 | 通信切断・承認待ち・同時タップ | 二重購入なし、永久busyなし、承認待ちを購入済みとしない |
| P03 | 再インストール・別端末で復元 | 同じApple Accountの有効権利を復元。起動で無断のApple同期を要求しない |
| P04 | 返金／取消、購入中に広告同意操作 | 失効を反映。購入中に広告画面を被せない |
| P05 | 設定ファイルpaidを改変 | 広告除去権利にならない。検証済みStoreKitだけが根拠 |
| D01 | 日本・EEA／UK／US対象地域テスト | UMP最新確認と必要フォーム。拒否・閉じるで強制再同意や会話制限なし |
| D02 | 未成年・成人、プライバシー選択変更 | 正しいリクエスト設定。年齢変更が次の要求へ反映 |
