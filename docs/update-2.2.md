# LiveTalk 2.2 更新内容

旧版2.1について、利用者から「一応使える」と報告を受けた。2.2の実機動作や応答時間を確認した報告とは区別する。

## 日付と調べもの

毎回、端末の現在日時とタイムゾーンを質問の指示に含める。単独の「今日は何日」「今何時」などは端末の時計で即答する。時計がずれていれば回答もずれる。

既定は「必要なときに検索」。公式Responsesの `web_search` を利用し、「調べて」「検索して」、ニュース・最新情報・天気などの明示的な質問では検索を必須にする。通常の会話はモデルが必要性を判断する。毎回検索・検索しないも選べる。対応するモデル、アカウント、組織の許可が必要で、利用できない場合は最新情報を確認したと装わず説明する。

検索結果の要点をVOICEVOXで読み上げ、検証済みのURL引用を「返答を見る」に表示する。リンクはタップ時だけ外部ブラウザーで開く。引用記号を発音せず、重複・不正なURLを除外する。会話内容やURLは診断ログに保存しない。

## 考え方と会話速度

「インスタント」はこのアプリの速度優先プリセット。ChatGPTサイトのInstantモデルそのものを指定する名前ではない。選んだモデルの利用可能な思考レベルから最も低いものを使う。モデルが思考なしに対応しなければ「低」などを使い、その内容を画面に示す。

サーバーが公開する対応レベルを優先し、不足する場合は公式資料で確認したモデルのみに保守的な対応表を使用する。未知のモデルでは標準設定を使い、未対応のレベルを捏造しない。低・中・高・極高・最大は対応モデルで選べる。高・極高・最大は品質優先で、速度向上の設定ではない。

話し終わりの無音を0.7秒から既定0.5秒へ、認識確定を待つ上限を0.6秒から0.25秒へ変更。文の途中の長い間を許す「ゆっくり話せる」では0.8秒・0.4秒にする。再聴取待ちはスピーカー420ms基準、イヤホン120msに変更。先行合成は継続し、12文字で区切っていた公式会話の初回長を18文字にして過度な細切れを減らす。

検索・深い思考を45秒で誤停止しないよう、待機中120秒、深い思考300秒、本文ストリーム60秒の停止監視に変更。利用者は途中で停止できる。診断には送信からGPTの最初の本文までと、最初の音声再生開始までの時間だけを表示する。人の会話と同等の応答時間は実測前に保証しない。

## CarPlay

対応コードを同梱する。音声サービス中のCPVoiceControlTemplate、起動直後の音声会話、話す・終了の操作、端末内音声認識、短文の先行合成、検索、引用をiPhoneで後から確認する処理を実装する。会話の本文・検索画像を車載画面へ表示しない。

CarPlayの会話はネイティブで動かし、画面を閉じたWebViewのタイマーに依存しない。認証更新とVOICEVOX合成の処理をiPhone画面と共有し、両方で同時に録音しない。CarPlay終了・切断・着信・音声経路の喪失で録音と再生を停止する。会話中だけ音声セッションを有効にする。

Appleの音声会話用権限 `com.apple.developer.carplay-voice-based-conversation`、承認済みのプロビジョニング、iOS 26.4以上が必要。無料Apple Account用IPAはこの権限を追加せず `LTCarPlayEnabled=false` とする。車載画面に表示される版、CarPlay実機検証済み版、販売承認済み版とは称さない。

Apple承認を受けた後に `LIVETALK_CARPLAY=approved` のビルドで専用権限・音声の背景動作を有効にし、該当プロファイルで署名する。無料アカウントのSideloadly署名にこの権限を足しても代替できない。詳細は[CarPlay準備](carplay.md)。販売用ChatGPT接続は既存の申請要件が別途残る。

## 検証の範囲

JavaScriptの会話・画面・設定テスト、PythonのIPA梱包テスト、Swiftの日時・思考レベル・検索要求・出典・短文処理テストを実行する。MacでiPhone向けに実際にコンパイルしたIPAを配布する。模擬テストの成功と、利用者アカウントでの検索・音声・車載機の実測を区別する。
