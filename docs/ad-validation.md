# 広告の実機確認手順

2026-10-07。GMA 13.11.0 / UMP 3.1.0。以下は実施手順であり、実機の試験済みという報告ではない。評価版は公式テストIDのみを使用する。

| 手順 | 期待結果 |
|---|---|
| 未同意／権利確認中／購入済みで起動 | 同意・権利がない間にGoogleへの広告要求を開始しない。購入済みなら同意確認も開始しない |
| 広告を使わないを選択 | 会話が使える。新しい広告を読み込まない |
| 成人／13〜17歳を選択しUMP確認 | 設定画面だけにテストバナー。未成年者設定が対応する |
| 成人から未成年者へ変更 | 次の広告要求に年齢設定を反映 |
| アプリの確認画面／UMP中に背景へ移動・復帰 | 古い結果を捨てる。必要なら再度設定する |
| 撤回・全データ削除後に遅い結果が返る | 再同意・再表示しない |
| 会話・読み上げ・待機音声・CarPlay・購入開始 | バナーを除去し、操作を重ねない |
| 広告を開いて戻る | 通話停止、広告画面の終了を正しく反映。設定を再び使える |
| UMP／広告の通信断と再読み込み | 非表示、自動のエラー再試行なし、明示操作だけで再確認 |
| 購入・復元・返金 | 権利に従い条件を変更。購入処理中に広告を開始しない |
| 通信・統合マニフェスト | 会話・音声・トークン・参照URLが広告要求にないこと、SDK自身の送信項目を確認 |

地域別フォーム・プライバシー選択はGoogleのテスト設定で確認する。最終版へ地域強制やデバッグ端末IDを残さない。停止前にSDKが開始した通信をすべてキャンセルしたとは報告しない。

端末・OS・版・設定・匿名化した証拠を記録してから本番の検証フラグを更新する。識別子や個人情報を公開の証拠へ残さない。[Googleの公式手順](https://developers.google.com/admob/ios/privacy)。
