# LiveTalk 2.5 — 課金・広告・公開文書の改善

無料版と買い切り広告除去（日本向け希望価格980円）の会話機能は同じ。アプリの月額課金は設けない。実際の購入価格はAppleの表示を使い、ChatGPTの無制限枠は含めない。

- 同時の購入権利確認が古い状態を返す問題を修正。購入前にもAppleの現在の権利を再確認し、他で購入済みになった場合は再購入を開始しない。
- 広告の確認画面・UMP更新・プライバシー画面の各完了時に中断・撤回を確認。古い操作で同意や広告が復活しないようにする。
- 未成年者向け設定を次の広告要求ごとに反映。広告画面を閉じた後の復帰も修正。
- 失敗時に「広告を再読み込み」を追加。広告の確認を自動反復せず、会話は継続できる。
- アプリ内の運営者を「ぞこーばスタジオ」、窓口をdoude424@gmail.comに統一。Web版の規約を同じ本文から生成し、差異を検査。
- StoreKit Testingに並行の権利確認と古い無料状態からの再購入防止を追加。UIとSwiftの広告方針にも回帰検証を追加。

公開準備版は実課金・収益広告を無効にしている。Appleの会員有効化、商品・販売契約、AdMob設定、OpenAIの商用許可・本番接続、音声権利と実機の最終検証は残る。書類の準備を販売許可や審査完了とは扱わない。
