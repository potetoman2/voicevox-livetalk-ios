# 2.8 音声条件とストリーミングの修正

2026-10-08。ChatGPTログイン方式を維持し、商用承認を待つという利用者の選択を反映。運営者負担のAPIへ変更しない。GPT接続・実購入・収益広告・CarPlayは承認と必要な確認まで無効。

初期音声は公式の安定版VVM 0.16.4にあるNemo n0.vvmへ変更した。女性6声・男性3声。モデルのSHA-256を配布メタデータと固定値で確認し、暗号化されたモデルを改変しない。四国めたん等の旧モデルは2.8に同梱しない。2.7以前の成果物と動作中のiPhoneは維持。

Nemoの共通クレジット「VOICEVOX Nemo」を台帳・画面・同梱条件に表示し、詳細規約をオフラインで同梱する。旧設定に残る未同梱のスタイルは準備時に利用可能なスタイルへ変更する。条件確認をNemo用に更新し、旧モデルの同意で自動通過しない。

[公式VVM規約](https://github.com/VOICEVOX/voicevox_vvm/blob/0.16.4/README.md)はアプリへの組み込み・再配布と商用利用を許諾している。[Nemo規約](https://voicevox.hiroshiba.jp/nemo/term/)はクレジットを条件に生成音声の商用利用を許諾している。禁止用途と規約更新も適用される。特定のアプリや全用途の安全を認定する許可証ではない。

SSE返答の空のdata行を無制限に蓄積する不具合を修正。イベントを4096行・結合後256KiBまでに制限し、改行のバイト数を含める。境界、空行、次イベントへのリセットをSwiftで試験する。

CIは実際のNemoモデルを同じC++ブリッジとCORE 0.17.0で合成する試験を追加した。9声すべての非無音WAVを確認する。macOSでの推論であり、iPhoneの発声・遅延・音声経路の試験とは区別する。[CI 37788492290](https://github.com/potetoman2/voicevox-livetalk-ios/actions/runs/37788492290)で9声の実合成・iPhone用ビルド・Apple課金9件と終了通知の統合3件が成功。SSEを含むSwift154項目、JavaScript82件、Python45件も合格。実端末のSandbox購入・広告・音声経路とは区別する。モデルと同梱規約の照合は[確認記録](evidence/nemo-voice-review.txt)に保存した。

AdMobアカウントの承認表示を確認済みとして記録を更新した。アプリは要審査、同意メッセージは未公開、収益は開始していない。提供先をGoogleだけに限定する設定案は本人の明示承認待ち。
