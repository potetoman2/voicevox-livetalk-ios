# LiveTalk 2.2 — VOICEVOXで音声会話
2026-10-06。iPhone単体で音声認識とVOICEVOX合成を行い、ChatGPTの利用枠で返答を受け取る個人評価版です。

## 2.2の追加機能
日付・時刻の即答、最新情報・調べもののネット検索、参照ページの表示、インスタントと対応モデルの思考レベル、会話テンポの選択、応答時間の表示を追加しました。

ホームの「インスタント · 必要なときに検索」を押すと設定へ進みます。「今日のニュースを調べて」「〇〇について検索して」と声で頼めます。検索はアカウントとモデルの対応が必要です。

CarPlay用コードを追加しました。車載画面への表示はAppleの権限承認後に、対応した署名とiOS 26.4以上で有効になります。無料アカウント用IPAは引き続きiPhone用で、CarPlay対応済みの配布物ではありません。[更新内容](docs/update-2.2.md)、[CarPlayの準備](docs/carplay.md)。

## 最初の使い方
1. 「音声を準備する」で音声の利用条件を確認します。
2. 「Continue with ChatGPT」を押します。ブラウザーでログインし、LiveTalkにChatGPTの利用枠を使う許可を与えます。
3. 接続済みになったら「会話を始める」を一度押します。初回のマイク・音声認識の許可はご自身で行ってください。
4. 話し終わると返答し、返答後は自動で次の声を聞きます。「終了」で会話を終えます。

文章のコピー・貼り付けは音声会話に必要ありません。読み上げだけを使う補助機能はホーム下部にあります。
APIキーの入力は不要です。内部では公式Responses APIをOAuthで呼び出します。利用枠の対応・残量・許可によって接続できない場合があり、無制限・全アカウント対応とはしていません。
既存のChatGPTチャット、メモリ、履歴は自動で引き継ぎません。このアプリ内の会話の文脈を送信します。

## 自然な会話の流れ
日本語の端末内音声認識 → マイクの無音で話し終わりを判定 → GPTの返答を生成中から取得 → 短文を先行合成・再生 → 自動で聞き取りを再開します。
スピーカーでは自分の返答を誤検出しないよう、返答中のマイクを休めます。途中で話す場合は「話し始める（割り込み）」を押してください。
イヤホン使用時は「声と設定」→「会話の聞き取り」で、返答中の聞き取りを有効にできます。認識した声で返答を止め、新しい質問へ進みます。誤検出や応答時間は実機で確認が必要です。
完全な同時双方向通話や、特定の応答秒数は保証していません。

## 声と画面
暖かい白、淡いブルー、ピーチ色。会話と設定の2画面です。
話速・音高・抑揚・音量・感情補正・前後無音・句読点の間、人格プリセット、話者とスタイルを調整でき、自動保存します。
感情補正は言葉による判定です。同梱モデルには四国めたん・ずんだもん・春日部つむぎ・雨晴はうがあります。

## 接続とデータ
OAuthのstate・nonce・PKCE、公開鍵によるIDトークン署名検証を行います。戻り先はこのiPhoneの127.0.0.1だけで待ち受け、認証の終了・取消・期限で閉じます。
接続情報はiPhoneのKeychainに保存し、ブラウザーJavaScript、設定書き出し、ログにトークンを渡しません。
利用モデルはログインしたアカウントの公式モデル一覧から取得します。「声と設定」の接続欄でアカウント・モデルを変更できます。
「ログアウト」で進行中の返答を停止し、更新用の接続情報を取り消して端末から消去します。遠隔解除を確認できない場合は画面に表示し、ChatGPTの設定から解除できます。
音声は端末内で文字に変換し、質問と直近の会話の文脈をOpenAIに送信します。会話はアプリの設定・診断ログに保存せず、メモリー内だけで保持します。OpenAI側の処理条件と利用枠も適用されます。

## Windowsから更新
成功したMacビルドの未署名IPAをSideloadlyで、前回と同じApple Account・端末へ上書きします。旧版を先に削除する必要はありません。
署名とログインは別です。SideloadlyはiPhoneへの導入に使い、アプリのChatGPTログインは導入後に行います。
無料Apple Accountの署名には期限などの制限があります。販売用の配布はこの方法では完成しません。

## 開発と検証
- Node.js 24: `npm ci` → `npx playwright install chromium` → `npm test`
- Python 3.12+: `python tests/ipa.test.py`
- Mac: GitHub ActionsがJavaScript、梱包、入力URL、音声ターン、OAuth/SSE/署名検証、iPhone向けコンパイルを実行します。
- [2.0までの20回の改善](docs/improvement-cycles.json)は履歴として保持し、2.1の変更は[音声会話の更新記録](docs/conversation-update.md)に分けています。
- 画面テストと会話テストの音声・マイク・認証は模擬です。実機のGPTログイン・発声・応答時間を確認した意味ではありません。

## 販売
この接続方式は公式に公開されている、公開ソース・ローカルアプリ向けのChatGPT利用枠の接続方式です。有料・遠隔提供アプリへの導入はOpenAIへの申請が必要です。
評価版は販売許諾・App Store審査承認済みではありません。`LIVETALK_DISTRIBUTION=store` では、申請未完了のChatGPT接続と旧Web画面の自動操作をネイティブ側から無効にします。
[販売前に残る事項](docs/release-readiness.md)、[第三者ライセンス](THIRD_PARTY_NOTICES.md)。VOICEVOX各音声の条件はアプリ内の利用条件でも確認できます。
