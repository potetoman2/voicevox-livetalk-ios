# LiveTalk 2.0 — iPhone用・API不要の読み上げ
2026-10-06 更新。WindowsからGitHubのMacビルドでiPhoneアプリを作れます。

## 最初の使い方
1. LiveTalkを開き、「音声を準備する」→利用条件を確認します。
2. ChatGPTで返答をコピーします。
3. LiveTalkに戻り「貼り付けて読み上げる」を押します。
4. 声を変えるなら「設定」へ。変更は自動保存されます。

ChatGPTへのログインやAPIキーは、貼り付け読み上げには不要です。直接文章を入力することもできます。音声合成は端末内です。

## 自動連携を試す場合
「設定」→「通話の実験機能」→「実験機能を表示する」を有効にし、ホームの「通話を試す」を選びます。
「ChatGPTを開いて接続」→アプリ内でログイン→入力欄が表示されたら「接続する」→「話しかける」。
マイクと日本語の端末内音声認識を許可してください。ログイン方式によってはアプリ内ブラウザーが拒否されます。その場合は貼り付け読み上げを使用してください。

**自動連携は非公式・実験機能です。完全な双方向通話、任意のログイン方式、将来のChatGPT画面との互換性を保証しません。OpenAIの利用規約では返答の自動取得を制限しており、この方式を販売機能として保証することはできません。** 公式APIによる連携は未実装です。API不要という依頼を維持しています。

## 声の設定
話速・音高・抑揚・音量・感情補正・前後無音・読点と文末の間を調整できます。人格プリセットは声の設定と、実験通話で任意に添える質問用プロンプトです。感情補正は言葉による判定で、GPTによる感情パラメータ生成ではありません。
同梱の0.vvmには四国めたん・ずんだもん・春日部つむぎ・雨晴はうがあります。実際の話者とスタイルをモデルから列挙します。

## ショートカットで文章を渡す
iPhoneの「ショートカット」で、共有シートからテキストを受け取るショートカットを作れます。
「URLエンコード」で文章をエンコードし、「URL」を `livetalk://read?text=［エンコードした文章］` にして「URLを開く」を追加します。
LiveTalkで受け取る文章を確認し、「この文章を読み上げる」を押します。専用の共有拡張はありません。自動再生はしません。

## Windowsから更新版を入れる
1. GitHubの成功したビルドから「LiveTalk-iOS-unsigned」を取得・展開します。
2. iPhoneをUSB接続し、ロックを解除します。
3. 導入済みのSideloadlyを開き、新しいIPAを選びます。同じApple Accountで上書きしてください。
4. 「Start」を押し、Appleの認証はご自身で行います。
5. iPhoneでLiveTalkを開きます。必要なら自分のデベロッパAPPを信頼し、デベロッパモードを有効にします。

IPAは未署名です。無料Apple Accountによる個人用署名には期限等の制限があり、販売用配布には使えません。旧版はこの端末で起動まで確認済みですが、2.0の実機動作は別途確認が必要です。

## 開発・ビルド
- Node.js 24: `npm ci` → `npx playwright install chromium` → `npm test`
- Python 3.12+: `python tests/ipa.test.py`
- macOS: `swiftc ios/LiveTalk/IncomingText.swift tests/incoming/main.swift -o /tmp/livetalk-intake` → 実行
- Macのビルド: `bash scripts/build_ios_cloud.sh`
- Windows: `scripts/build_ios_windows.ps1` がクラウドビルドの案内を表示します。
- ビルド環境変数 `LIVETALK_DISTRIBUTION=store` で自動連携をネイティブ側から無効にします。標準は実機評価用 `preview` です。
